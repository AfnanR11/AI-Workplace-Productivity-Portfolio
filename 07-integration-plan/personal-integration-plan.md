# Personal AI Integration Plan

## Role

Project Manager - Media Production

The following plan identifies recurring tasks where Generative AI can support my productivity while maintaining human oversight.

---

## 1. Project Status Updates

### Recurring Task

Collecting updates from multiple production team members and preparing a clear project status report.

### Expected Benefit

- Saves time.
- Makes scattered information easier to understand.
- Helps identify blockers and risks.

### Preferred Prompt or Workflow

Project Status Brief from the Prompt Library.

### Risk or Verification Requirement

The summary must be checked against the original updates to ensure that AI has not invented or omitted important information.

### Frequency

Weekly or whenever major project updates are received.

### What Success Looks Like

A clear project status report is produced faster and allows the project team to identify priorities and next actions.

---

## 2. Action Item Extraction and Task Follow-Up

### Recurring Task

Extracting tasks from meetings and following up on incomplete production activities.

### Expected Benefit

- Reduces the risk of missing action items.
- Improves task visibility.
- Makes follow-up communication faster.

### Preferred Prompt or Workflow

Action Item Extractor and Follow-Up Message Generator.

### Risk or Verification Requirement

Task owners and deadlines must be confirmed against the meeting notes or project tracker.

### Frequency

After production meetings and project review sessions.

### What Success Looks Like

Every important action item is documented, assigned, and followed up appropriately.

---

## 3. Production Planning

### Recurring Task

Breaking a media production goal into phases, tasks, milestones, and dependencies.

### Expected Benefit

- Faster initial project planning.
- Better organization of complex production activities.
- Clearer visibility of project dependencies.

### Preferred Prompt or Workflow

Production Schedule Planner using:

Goal → Mechanisms → Phases → Tasks

### Risk or Verification Requirement

The project manager must review all proposed tasks, dependencies, resources, and timelines before implementation.

### Frequency

At the beginning of each new project and whenever a major change occurs.

### What Success Looks Like

The production team has a clear and realistic plan with defined phases, tasks, responsibilities, and milestones.
