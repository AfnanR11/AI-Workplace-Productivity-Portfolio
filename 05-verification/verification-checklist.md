# AI Output Verification Checklist

AI-generated content should not be used automatically for project decisions.

Before using an AI-generated output, I follow this checklist:

## Verification Checklist

- [ ] Identify what information the AI output is based on.
- [ ] Check whether the output accurately reflects the original source.
- [ ] Verify names, dates, deadlines, and numbers.
- [ ] Check that AI did not invent missing information.
- [ ] Review whether action items have clear owners.
- [ ] Check whether important risks or dependencies were missed.
- [ ] Review the tone and format for the intended audience.
- [ ] Make the final decision through human review.

---

# Worked Example

## Output Being Verified

The AI-generated project status summary from the Information Workflow section.

### Step 1 — Identify

The output was created from fictional updates from the script, filming, editing, audio, and graphics teams.

### Step 2 — Set Criteria

I checked:

- Accuracy
- Completeness
- Missing information
- Task ownership
- Dependencies

### Step 3 — Test

I compared the AI output with the original updates.

### Findings

| Verification Item | Result |
|---|---|
| Script approval | Correct |
| Editing progress | Correct |
| Voice-over dependency | Correct |
| Filming location blocker | Correct |
| Missing deadlines | Correctly marked as [Not Specified] |
| Task ownership | Only assigned where supported by the source |

### Step 4 — Confirm and Decide

The output was acceptable after human review.

No invented deadlines or unsupported project details were found.

## Final Decision

The structured project summary can be used as a project management reference, but any decisions about deadlines, resources, or task reassignment remain the responsibility of the Media Production Project Manager.
