# Responsible AI in Media Production Project Management

AI can support project management activities, but it must be used responsibly.

---

## 1. Accuracy

AI-generated summaries, schedules, and action items must be checked against the original project information. AI should not be assumed to be correct automatically.

---

## 2. Accountability

The Media Production Project Manager remains responsible for project decisions, communication, task assignments, and final outputs.

AI can support the work, but it does not take responsibility for decisions.

---

## 3. Confidentiality

Confidential client information, production contracts, unpublished media, internal budgets, and sensitive project documents should not be entered into public AI systems.

Examples used in this portfolio are fictional or anonymized.

---

## 4. Privacy

Personal information about employees, freelancers, clients, or other stakeholders should be protected.

Only information necessary for the task should be processed.

---

## 5. Bias

AI suggestions should be reviewed to ensure that task assignments, recommendations, or evaluations are not unfair or based on unsupported assumptions.

Human judgment is required when assigning responsibilities or evaluating team performance.

---

## 6. Human Oversight

A human reviews AI-generated content before it is used.

The final decisions about deadlines, task assignments, project priorities, and media approval remain with the responsible project team.

---

# Green / Amber / Red Classification

| Information Item | Classification | Reason |
|---|---|---|
| Fictional project status update | Green | Safe to use because it contains no real confidential or personal information |
| Anonymized task list | Green | Can be used if names and sensitive project details are removed |
| Internal production schedule | Amber | May contain sensitive operational information and should be reviewed before sharing |
| Real client contact details | Red | Personal and confidential information should not be entered into public AI tools |
| Unreleased media files | Red | Confidential intellectual property that should not be uploaded to public systems |

---

# Responsible Use Decision

For this portfolio, all examples use fictional or anonymized information.

Before using AI in a real media production environment, I would review the information to determine whether it contains confidential, private, personal, or commercially sensitive data.
