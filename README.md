## 🎯 Project Overview

This portfolio demonstrates how generative AI can support a Project Manager - Media Production in completing recurring workplace tasks more efficiently.

The portfolio covers practical applications in prompt engineering, professional communication, information processing, production planning, task coordination, verification, and responsible AI use.

All examples are connected to one fictional media production scenario. AI is used as a productivity assistant, while accuracy, judgment, task assignment, and final approval remain under human responsibility.

---

## 🎬 Selected Workplace Scenario

The selected role is **Project Manager - Media Production**, responsible for coordinating media production activities from planning through final delivery.

The role includes:

- planning media production projects;
- assigning tasks to production team members;
- tracking project progress and deadlines;
- following up on outstanding tasks;
- organizing production meetings and updates;
- identifying risks, blockers, and dependencies;
- coordinating filming, editing, graphics, and audio activities;
- preparing professional stakeholder communication;
- supporting media production and post-production; and
- verifying AI-assisted outputs before use.

## 💡 Key Learnings

1. Clear prompts produce more accurate and useful production-management outputs.
2. AI-generated project information must be checked against the original source.
3. Missing owners, dates, deadlines, and decisions should be marked as `[Not Specified]`, not invented.
4. AI can reduce repetitive administrative work such as summarizing updates and preparing follow-ups.
5. Human judgment remains essential for task assignment, prioritization, project decisions, and final media approval.
6. Confidential production information and personal data require appropriate privacy controls.
