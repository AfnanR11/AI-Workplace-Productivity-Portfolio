# Prompt Library

This prompt library demonstrates structured use of generative AI for recurring tasks performed by a Media Production Project Manager. The prompts support production tracking, task assignment, team follow-up, scheduling, and stakeholder communication.

| Prompt Name | Workplace Task | Framework | Prompt Expected Output |
|---|---|---|---|
| Production Status Brief | Turn scattered production updates into a clear project status report. | C.A.R.E. | Concise status brief with progress, delays, risks, deadlines, and recommended actions. |
| Task Assignment Planner | Convert production requirements into clear assignable tasks. | C.A.R.E. | Structured task list with role, deliverable, priority, deadline, dependency, and status. |
| Production Follow-Up Message | Follow up on pending or overdue production tasks. | C.A.R.E. | Professional, concise follow-up message with required action and requested update. |
| Production Schedule Planner | Build a schedule across production phases and dependencies. | R.C.T.O. | Phased production schedule with tasks, roles, deadlines, dependencies, and milestones. |
| Stakeholder Production Update | Convert internal production information into a stakeholder update. | C.A.R.E. | Concise professional update covering status, progress, milestones, risks, and required actions. |
